# FigNest 4.3.0 — Inspect, annotate, and compare in place

[English](#english) · [简体中文](#中文)

This release brings the image tools and workflow improvements developed after
4.1.0 into one public update. Open a figure, inspect a detail, add a reference
line or annotation, and save or export it without leaving the viewer.

## Highlights

- **Image tools:** pan, box zoom, pixel distance, pixel rulers, fit and 100% remain
  available with annotations collapsed. Add text, arrows, lines, shapes, freehand
  strokes and horizontal/vertical guides. Clear all marks with undo support.
- **Annotations:** choose default panel expansion; save with ⌘S / Ctrl+S even
  while typing. Save all edited comparison images together. Separate save,
  coordinate and mode indicators; close/quit/reload guards and errors retain edits.
  Export a marked PNG or annotation JSON, and view saved marks in new offline HTML.
- **Comparison:** select 2–4 images and use right-click or the persistent bottom
  bar. The active image is explicit, layouts adapt to image proportions, and
  relative zoom/pan linking is optional. View one image and return to the same group.
- **Browsing:** scoped search, removable filter chips, recovery from empty results,
  persistent selection actions, view selected/return, title-click preview, keyboard
  navigation, and searchable folder membership with clear save feedback.
- **Packaging:** minimum macOS requirements include bundled runtime dependencies;
  current runtime licenses are included. CI covers image geometry and UX behavior.

## Downloads and compatibility

- **DMG / ZIP:** the same standalone 图匣.app for **Apple Silicon, macOS 27+**.
- **Source ZIP:** code, tests, bilingual documentation and skill entrypoint.
- **Skill ZIP:** reusable `image-collection-viewer` folder.
- **SHA256SUMS.txt:** checksums for the four archives.

Build 13 includes Python 3.14.7 and PyInstaller 6.22.3. It is ad-hoc signed and
not Apple-notarized. No Intel binary is supplied. Although the native window
targets macOS 13, this packaged Python runtime and its libraries require macOS 27;
the app's system requirement now states that accurately. The source browser
edition still runs with Python 3.10+. UI labels are currently Chinese.

## Updating from 4.1 or a local 4.2 build

Save annotations, finish imports/exports, and close live viewers. Stop the existing
library service before replacing the app:

```sh
"/Applications/图匣.app/Contents/Resources/backend/library-backend" stop
```

Adjust the app path if installed elsewhere; add `--data /path/to/store` before
`stop` for a custom store. Preserve the old app and a backup of the entire data
folder before updating. Launch the new app, and reopen the live browser URL
reported by `launch` if its port changes.

The default data folder stays `~/Pictures/ImageCollectionViewer`. SQLite
`user_version` remains 6; an additive `image_markup` table stores original-pixel
documents, content identity and revisions. Existing library records and source
files are retained. Keep the data backup if returning to an older app.

Pixel measurements are not calibrated physical units. Linked views use relative
positions; each image retains its own coordinates and annotations. PNG export is
limited to 64 million pixels. Offline HTML is a read-only snapshot; existing
exports are not rewritten. See the [user guide](https://github.com/QiushanHuang/FigNest/blob/v4.3.0/docs/USER_GUIDE.md)
and [validation](https://github.com/QiushanHuang/FigNest/blob/v4.3.0/docs/validation.md).

## 中文

[English](#english) · [简体中文](#中文)

本次将 4.1.0 之后的图片工具和便利性改进合并为一个公开更新。
打开图片后，可以细看局部、画参考线和标注，再保存或导出。

### 主要更新

- **图片观察**：平移、框选放大、像素测距、像素标尺、适应窗口与 100% 常驻。
  支持文字、箭头、直线、形状、画笔、水平/垂直参考线；一键清除可撤销。
- **标注与保存**：可选默认展开，文字框内也支持 ⌘S / Ctrl+S，比较支持保存全部。
  坐标、模式与保存状态独立显示；关闭、退出、重新载入前保护未保存编辑，
  保存失败保留内容。支持标注 PNG、JSON 与新离线 HTML 中的已保存标注。
- **并排比较**：选择 2–4 图后右键或使用底部常驻栏进入。
  明确显示当前操作图片，按比例自动布局，可选相对缩放/平移联动；
  单独查看后可返回原比较组。
- **找图与整理**：当前搜索范围、筛选条目、无结果恢复入口；
  常驻选择栏、查看已选/返回、标题预览和键盘导航；
  文件夹搜索、部分成员提示和明确保存反馈。
- **发行与检查**：系统要求包含实际运行环境要求，补齐当前依赖许可证，
  CI 增加图片几何与交互行为检查。

### 下载与兼容性

- **DMG / ZIP**：同一个独立 图匣.app，**Apple Silicon · macOS 27+**。
- **源码 ZIP**：代码、测试、中英文文档和 skill 入口。
- **Skill ZIP**：可复用的 `image-collection-viewer` 目录。
- **SHA256SUMS.txt**：四个发行包的校验值。

构建号 13，自带 Python 3.14.7，使用 PyInstaller 6.22.3 打包。
采用 ad-hoc 签名，尚未经过 Apple 公证；本版不提供 Intel 二进制包。
原生窗口虽面向 macOS 13，本次 Python 与依赖实际要求 macOS 27，
应用包已据此修正系统要求。源码网页版仍支持 Python 3.10+，当前界面为中文。

### 从 4.1 或本地 4.2 更新

先保存标注、完成导入导出并关闭实时窗口，停止现有图库后台服务后替换应用：

```sh
"/Applications/图匣.app/Contents/Resources/backend/library-backend" stop
```

安装在其他目录时调整应用路径，自定义数据目录在 `stop` 前加
`--data /path/to/store`。更新前保留旧应用并备份整个数据目录。
启动新版后，若服务端口改变，可用 `launch` 提供的新地址重新打开实时网页版。

默认数据目录仍为 `~/Pictures/ImageCollectionViewer`，SQLite `user_version`
仍为 6，新增 `image_markup` 表保存原始像素标注、内容身份和版本。
原有图库记录与源文件保留；需要返回旧版时保留更新前的数据备份。

像素测量不做物理单位标定。联动使用相对位置，各图保留自己的坐标和标注。
PNG 导出上限为 6400 万像素。离线 HTML 为只读快照，旧导出不会自动改写。
详见[使用指南](https://github.com/QiushanHuang/FigNest/blob/v4.3.0/docs/USER_GUIDE.md)
与[验收说明](https://github.com/QiushanHuang/FigNest/blob/v4.3.0/docs/validation.md)。
