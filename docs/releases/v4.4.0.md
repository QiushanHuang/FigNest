# FigNest 4.4.0 — A clearer workspace

[English](#english) · [简体中文](#中文)

FigNest 4.4 brings the next action closer to the content: the library, import,
browsing and offline views have fewer repeated labels and more room for images.

## What's changed

- **Browse:** in a wide window the enabled detail panel appears after selection;
  in a narrow window it opens from **Details**. Counts and active filters remain visible without repeating the scope.
  The library title opens it directly; the new-library action clearly starts import.
- **Import and organize:** choose files first, then the target library. Optional
  import rules are grouped together; active saved rules are expanded. Automatic
  HTML export stays visible. Folder membership still saves immediately, with
  partial membership shown.
- **Narrow windows:** expand the navigation to reach libraries, nested folders
  and their actions. Selection, visible keyboard focus, control names and expanded
  states remain available.
- **Compare and export:** single-image previews avoid duplicate zoom controls;
  comparison identifies actions that apply to all images. New offline snapshots
  hide filters with only one possible value and unavailable one-item comparison.
- **Accurate smart folders:** Save filters is available in All assets, a library
  or Favorites. Folder membership, Unfiled, Duplicates, Hidden and selected-item
  scopes cannot currently be encoded by smart-folder rules, so their save action
  is omitted rather than silently creating a broader result.
- **Safety:** recovery and permanent-removal consequences remain explicit; unsaved
  annotations are still protected. Existing offline exports are not rewritten.

## Downloads and compatibility

- **DMG / ZIP:** 图匣.app for Apple Silicon and macOS 27+.
- **Source ZIP / Skill ZIP:** source, tests and documentation or the reusable skill.
- **SHA256SUMS.txt:** checksums for the four archives.

The package includes its runtime, uses an ad-hoc signature, and is not Apple
notarized. The source browser edition needs Python 3.10+. The interface is in
Chinese. Pixel measurements are not calibrated physical measurements.

## Update

Save annotations, finish imports and exports, and close live viewers. Back up the
whole `~/Pictures/ImageCollectionViewer` directory, then stop the existing service
before replacing the app:

```sh
"/Applications/图匣.app/Contents/Resources/backend/library-backend" stop
```

Adjust the path for a different installation; use `--data /path/to/store` before
`stop` for a custom store. The database schema remains version 6 and source files
are not moved. New offline HTML uses the updated interface; previous exports remain
independent snapshots. See the [user guide](https://github.com/QiushanHuang/FigNest/blob/v4.4.0/docs/USER_GUIDE.md).

## 中文

[English](#english) · [简体中文](#中文)

4.4 精简了图库、导入、浏览和离线界面，让主要操作更清楚，并为图片留出更多空间。

### 主要更新

- **浏览**：宽窗口启用详情面板时，选中素材后显示详情；窄窗口可点击“详情”打开。数量和活跃筛选保留，减少重复范围说明。图库标题可直接打开，新增图库入口明确为导入。
- **导入与整理**：先选择文件，再指定图库；次要导入规则集中在展开区，已生效的规则会展开显示，自动导出选项始终可见。文件夹归类仍即时保存，并显示部分成员状态。
- **窄窗口**：展开导航即可进入图库和多级文件夹；保留选择状态、控件名称、展开状态和可见键盘焦点。
- **比较与导出**：单图预览去掉重复缩放入口；比较时标明作用于全部图片的操作。新离线快照收起只有一个取值的筛选器，以及单素材时无法使用的比较操作。
- **智能文件夹范围**：全部素材、图库和收藏可保存筛选。文件夹成员、未分类、重复内容、已隐藏和已选素材范围暂不能由智能规则表达，因此这些视图不再提供会丢失范围的保存操作。
- **安全与数据**：回收和永久删除的后果提示、未保存标注保护继续保留。旧离线导出不会被改写。

### 下载与兼容性

- **DMG / ZIP**：Apple Silicon、macOS 27+ 的图匣.app。
- **源码 ZIP / Skill ZIP**：源码、测试、文档或可复用 skill。
- **SHA256SUMS.txt**：四个发行包的校验值。

安装包自带运行环境，采用 ad-hoc 签名，尚未经过 Apple 公证。源码网页版需要
Python 3.10+；界面为中文。像素测距不代表经过标定的物理距离。

### 更新方法

保存标注、完成导入导出并关闭实时窗口。备份整个 `~/Pictures/ImageCollectionViewer`
目录，再停止现有服务后替换应用：

```sh
"/Applications/图匣.app/Contents/Resources/backend/library-backend" stop
```

安装在其他位置时调整路径；自定义数据目录在 `stop` 前加 `--data /path/to/store`。
数据库 schema 仍为 6，原始文件不会移动。新生成的离线 HTML 使用新版界面，
以前的导出仍为独立快照。详见[使用指南](https://github.com/QiushanHuang/FigNest/blob/v4.4.0/docs/USER_GUIDE.md)。
