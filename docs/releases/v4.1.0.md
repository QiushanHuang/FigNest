# FigNest 4.1.0

[English](#english) · [简体中文](#中文)

FigNest's first public release brings a local figure library, cross-project comparisons and portable offline galleries to macOS Apple Silicon.

## Highlights

- A visible Settings button plus native **FigNest → Settings… / ⌘,**.
- Display, import/export, storage and About controls in one panel, backed by the shared local database.
- New FigNest icon, standard Mac About window, version/build and copyright information.
- Nested and smart folders, batch tags/favorites/hiding, notes with attachments, and 2–4-image comparisons.
- Ordinary-file import, repeatable rules, Finder reveal and immutable HTML snapshots.

## Downloads

- **DMG**: drag 图匣.app into Applications.
- **ZIP**: the same standalone Apple Silicon application.
- **Source ZIP**: source, tests, documentation and the reusable skill entrypoint.
- **Skill ZIP**: installable `image-collection-viewer` folder with program/templates.
- **SHA256SUMS.txt**: distribution checksums.

Requires macOS 13+. Built for arm64 and verified locally on macOS 27; no Intel binary is supplied. The app includes its Python runtime. It is ad-hoc signed, not Apple-notarized; macOS may request first-launch approval.

The browser edition runs from source with Python 3.10+. An exported HTML needs neither the runtime nor an active server. UI labels are currently Chinese.

## Updating from a local 4.0 build

Quit FigNest, preserve a backup, then replace the app. The data directory and SQLite schema 6 are unchanged; your library records remain separate from the application bundle. Menu/shortcut acceptance, persistence checks and synthetic regression results are recorded in [validation](../validation.md).

## 中文

FigNest 首个公开版本，将本地素材整理、跨项目图片对照和可携带的离线图库整合到 Mac 应用中。

### 主要更新

- 更显著的设置按钮，原生 **FigNest → 设置… / ⌘,**。
- 显示、导入导出、存储、关于集中管理，与网页版共用本地数据库。
- 全新 FigNest 图标、标准 Mac 关于窗口、版本构建号与版权信息。
- 多级目录、智能目录、批量标签/收藏/隐藏、备注附件和 2–4 图对比。
- 普通文件导入、可复用规则、Finder 定位及独立 HTML 快照。

### 软件包

- **DMG**：将图匣.app 拖入 Applications。
- **ZIP**：同一个独立 Apple Silicon 应用。
- **源码 ZIP**：代码、测试、文档和可复用 skill 入口。
- **Skill ZIP**：可安装的 `image-collection-viewer` 目录，包含程序与模板。
- **SHA256SUMS.txt**：发行包校验值。

需要 macOS 13+，面向 arm64，在 macOS 27 完成本机验收；本版不提供 Intel 二进制包。
应用自带 Python 运行环境，采用 ad-hoc 签名，尚未经过 Apple 公证，首次打开可能需要系统确认。

源码网页版需要 Python 3.10+；独立导出的 HTML 不需要运行环境或服务。当前界面使用中文。

### 从本地 4.0 更新

退出应用、保留备份，再替换 App。数据目录与 SQLite schema 6 不变，图库记录与应用包分开保存。
快捷键、菜单、持久化与回归测试情况见[验收记录](../validation.md)。
